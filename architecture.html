System architecture

SiftBench compares AI code reviewers on pinned GitHub pull requests. A Python runner collects reviews, SQLite stores campaign state and evidence references, and a static web report presents the findings and human verdicts. Archived inputs and verdicts reproduce a score. A new review from a provider may differ even with the same inputs.

System context

A Developer Experience Engineer runs campaigns, a Staff Software Engineer validates findings, and an Engineering Manager compares outcomes for rollout. Proofline, Greptile, and CodeRabbit review separate pull requests in GitHub. GitHub Actions and AWS Lambda provide deployment evidence when relevant.
