Scoring scope and limits

Each app reviewed each pinned change once in a dedicated repository. The rubric stayed in the evaluator workspace. All 150 first eligible reviews were verified against their GitHub publications.

Two cases had unresolved findings and were excluded from the shared scores. The comparison describes this campaign. A single run per tool and case leaves run-to-run variation unmeasured.
