# SiftBench brand assets

The mark is a vector reconstruction of the supplied reference. The wordmark uses Manrope at weight 800, converted to outlines so the SVG displays independently of installed fonts.

- Use `logo-on-dark.svg` on a dark background and `logo-on-light.svg` on a light background. Both lockups also have transparent PNG versions.
- Use the corresponding `mark-*` asset for a collapsed sidebar or an icon-only slot.
- Use `favicon.svg` for the browser tab, `favicon.ico` for ICO support, `apple-touch-icon.png` for iOS, and `app-icon-192.png` or `app-icon-512.png` for installable web app manifests. The app icons use `purpose: "any"`.
- Use `brand.css` and the adjacent Latin variable WOFF2 to self-host Manrope. Set body text to 500, UI labels to 600, and headings to 700 or 800. `OFL-Manrope.txt` contains the font license.

[Manrope source and license metadata](https://github.com/google/fonts/tree/main/ofl/manrope)
